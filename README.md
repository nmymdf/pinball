# 鐵道劫案 RAILROAD ROBBERY（彈珠檯）
作者：ArchieKUO　版本 v3.9.1

- `pinball-desktop.html`：電腦版（雙擊用 Chrome / Edge 開啟；手機直式也能玩）
- `app/`：Android 版（WebView 包裝同一份遊戲）。推上 main 後 GitHub Actions 會自動打包，APK 在 `apk` 分支：
  https://github.com/nmymdf/pinball/raw/apk/Pinball.apk

## iPhone / iPad（網頁版）
GitHub 專案 Settings → Pages → Source 選 `main`，資料夾選 `/docs`。
之後用 Safari 開 https://nmymdf.github.io/pinball/ ，點分享 → 加入主畫面。
